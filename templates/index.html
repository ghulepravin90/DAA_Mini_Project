2. Master Theorem for Divide-and-Conquer Recurrences

Form: T(n) = a T(n / b) + f(n), where a ≥ 1 and b > 1. Let c = log_b(a).

  • Case 1: If f(n) = O(n^(c - ε)) for some ε > 0, then T(n) = Θ(n^(log_b a)) (Work dominated by leaves).
  • Case 2: If f(n) = Θ(n^c * log^k n) where k ≥ 0, then T(n) = Θ(n^(log_b a) * log^(k+1) n) (Work evenly split across tree levels; Merge Sort: T(n) = 2T(n/2) + O(n) yields Θ(n log n)).
  • Case 3: If f(n) = Ω(n^(c + ε)) for some ε > 0 and regularity condition holds (a*f(n/b) ≤ k*f(n)), then T(n) = Θ(f(n)) (Work dominated by root).

3. Essential DAA Viva Voce Questions & Answers

Q1: Why is Quick Sort preferred over Merge Sort for sorting arrays in practice?

QuickSort sorts in-place (auxiliary space O(log n) stack vs O(n) heap allocation for MergeSort) and exhibits exceptional cache locality because it iterates sequentially over contiguous memory blocks. Although its worst case is O(n²), randomized pivot selection or Introsort virtually eliminates this risk.

Q2: What is the fundamental difference between Backtracking and Dynamic Programming?

Backtracking solves Constraint Satisfaction Problems by depth-first searching a state-space tree and abandoning ("pruning") partial candidates as soon as they violate constraints (e.g., N-Queens, Sudoku). Dynamic Programming solves optimization problems exhibiting optimal substructure and overlapping subproblems by memoizing or tabulating subproblem solutions to prevent recomputation.

Q3: Why does Dijkstra's Algorithm fail when negative edge weights are present?

Dijkstra is a Greedy algorithm: once a vertex is marked "visited" and extracted from the priority queue, Dijkstra assumes its shortest path is permanently finalized. A negative edge encountered later could lower the distance to an already-visited vertex, invalidating this greedy assumption. Bellman-Ford (O(VE)) must be used instead.

Q4: What makes an algorithm "Stable"? Give examples.

A sorting algorithm is stable if two elements with equal keys appear in the output array in the exact same relative order as in the input array. Stable: Merge Sort, Insertion Sort, Bubble Sort. Unstable: Quick Sort, Heap Sort, Selection Sort.
